Web Design & Development

Level

In person, at our lab

Agreed when you enrol
Fees
Call or WhatsApp us

Learn how websites are planned, designed, built and published. You write real HTML, CSS and JavaScript from the first class, and you finish with a live website of your own.

What you’ll learn

  1. How the web worksBrowsers, servers, domain names and hosting, explained simply.
  2. HTML foundationsStructure pages with headings, links, images, lists and forms.
  3. Styling with CSSColour, type, spacing, and layouts with Flexbox and Grid.
  4. Responsive designPages that look right on phones, tablets and laptops.
  5. JavaScript essentialsVariables, events and the DOM, to make pages interactive.
  6. From design to codeTurning a layout into a clean, accessible web page.
  7. Tools of the tradeVS Code, browser developer tools, Git and GitHub.
  8. Going livePublishing your site online so anyone can visit it.

By the end, you can

  • Build a multi-page website from a blank file
  • Make a layout work on phones and laptops
  • Add interactivity with JavaScript
  • Publish and update a live website
  • Show a portfolio of work you built yourself

Tools

HTML, CSS, JavaScript, VS Code, Git and GitHub

Suited to

Complete beginners, students and school leavers, business owners who want their own website, and anyone thinking about freelancing.

Learn to design databases that keep information organised, accurate and easy to find. Every school, shop and business depends on one.

What you’ll learn

  3. Microsoft Access in depthTables, queries, forms and reports.
  4. Introduction to SQLSELECT, INSERT, UPDATE and DELETE.
