Learn how websites are planned, designed, built and published. You’ll write real HTML, CSS and JavaScript from the very first class — and finish with a live, mobile-friendly website of your own.

What you’ll learn

  1. How the web worksBrowsers, servers, domains and hosting — explained simply.
  2. HTML5 foundationsStructure pages with headings, links, images, lists and forms.
  3. Styling with CSS3Colour, typography, spacing, Flexbox and Grid layouts.
  4. Responsive designMake every page look right on phones, tablets and desktops.
  5. JavaScript essentialsVariables, events and the DOM — make pages interactive.
  6. Design to codeTurn a layout into a clean, accessible web page.
  7. Tools of the tradeVS Code, browser DevTools, Git and GitHub.
  8. Going livePublish your site online so anyone can visit it.

By the end, you can

  • Build a multi-page website from a blank file
  • Make any layout work on mobile and desktop
  • Add interactivity with JavaScript
  • Publish and update a live website
  • Show clients or employers a portfolio you built yourself

Ideal for

  • Complete beginners
  • Students & school leavers
  • Business owners
  • Aspiring freelancers

Learn to design databases that keep information organised, accurate and easy to find — the backbone of every school, shop and business system.

What you’ll learn

  1. Database conceptsTables, records, fields — and why structure matters.
  2. Designing tablesKeys, relationships and avoiding duplicate data.
  3. Microsoft Access in depthTables, queries, forms and reports.
  4. Introduction to SQLSELECT, INSERT, UPDATE and DELETE.
  5. Filtering & joining dataWHERE, ORDER BY and JOIN across tables.
  6. Keeping data safeValidation, backups and good data habits.
  7. Project: a records systemBuild a working system, such as student or inventory records.

By the end, you can

  • Design a well-structured database
  • Build forms and reports in Access

  • Keep records accurate and backed up
